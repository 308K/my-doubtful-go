## 核心特性

1. **轻量级全跨平台内核 (`github.com/egoist/mygo`)**
   - 免CGo纯Go编译，分别调用各操作系统原生WebView（Windows WebView2、macOS WKWebView、Linux WebKitGTK 4.1）。
   - 100%本地内存高速运算（10000条级数据清洗与测算 < 300ms），零外网请求、零数据泄露风险。
2. **多维财务风险预警分级体系**
   - 将5级应收账款账龄预警阶梯融入财务内控矩阵，支持在**「柔和预警色卡」**与**「经典预警色卡」**之间一键切换，并双向同步至UI看板与导出的Excel单元格高保真配色：

| 账龄区间 | 计提比例 | 经典预警 | 柔和预警 | 代表色 HEX | Excel 填充 / 字体色 | 业务状态与催收管控措施 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **1个月以内** (`0-30天`) | `1%` | 无 | **正常** | `#77DD77` | `#E2F0D9` / `#385723` | 正常管理（资金流转顺畅） |
| **1-3个月** (`31-90天`) | `5%` | 蓝色 | **关注** | `#77BBDD` | `#DDEBF7` / `#1F4E79` | 关注回款进度；纳入月度回款计划 |
| **3-6个月** (`91-180天`) | `20%` | 黄色 | **审慎** | `#FFDD88` | `#FFF2CC` / `#833C0C` | 电话/邮件催收；寄送对账单确认债权 |
| **6-12个月** (`181-365天`) | `50%` | 橙色 | **严控** | `#7777AA` | `#E4DFEC` / `#3B3838` | 指定专人跟进催收；下调信用额度；暂停新增赊销 |
| **1年以上** (`366天以上`) | `100%` | 红色 | **高危** | `#FF8899` | `#FCE4D6` / `#C00000` | 启动专项催收；评估诉讼时效与法务介入；全额计提 |

3. **五步式智能数据治理流水线 (5-Step Pipeline)**
   - **Step 1 结构探测与清洗**：智能识别表头（第4行），自动剥离表头前冗余注释行（3行）、过滤空白行（4行：`[3, 21, 58, 102]`）、剔除小计/合计行（5行：`[36, 68, 99, 131, 136]`）、哈希去重剔除重复单据（4行：`[132, 133, 134, 135]`），从136行原始数据提纯出**120笔**有效业务记录。
   - **Step 2 主数据对齐与8类缺失值推导**：内置20家标准客户档案（`CUST001`~`CUST020`）别名反查；自动统计各客户历史有效账期众数并修补8类缺失值（账期4、信用等级2、已收金额5、应收金额6、未收余额7、约定收款日5、逾期天数4、是否逾期4，共**37处**缺失单元格）。
   - **Step 3 9类财务异常审计与挂起分流**：
     - **6类原地修复并入表**（应收金额为负2、勾稽关系不平3、账龄与开票日期矛盾3、约定收款日与账期不符3、逾期天数矛盾3、逾期标识矛盾2）；
     - **3类实质性异常挂起隔离**（金额离群/低于2万元合理阈值7笔、已收大于应收溢缴超收3笔、未收余额为0仍挂账3笔，共**13笔**分流至《挂起异常清单》，确保**107笔**正常业务汇总基数真实准确）。
   - **Step 4 账龄测算与多维可视化看板**：支持动态调整报表基准日（默认 `2026-06-30`），实时联动账龄金字塔图、未收余额/坏账准备双环占比图、七大销售区域风险敞口雷达图，以及支持排序/多维筛选/单笔公式穿透复核的TanStack数据表格。
   - **Step 5 全量保留Excel原生动态公式导出**：生成包含5张工作表、**2432个原生Excel动态公式**的高保真财务工作簿。

## 全量动态公式架构 (`Excelize v2`)

导出的Excel工作簿绝不使用硬编码死数据，全部由 `'坏账准备与预警分析表'!$B$1`（`=DATE(2026,6,30)`）驱动级联重算：

- **Sheet 1 `应收账款明细(清洗后)` (107笔正常明细)**：
  - 未收余额 (`L{i}`): `=J{i}-K{i}`
  - 约定收款日 (`N{i}`): `=G{i}+M{i}`
  - 账龄天数 (`O{i}`): `='坏账准备与预警分析表'!$B$1-G{i}`
  - 逾期天数 (`P{i}`): `=MAX(0, '坏账准备与预警分析表'!$B$1-N{i})`
  - 是否逾期 (`Q{i}`): `=IF(AND(P{i}>0, L{i}>0), "是", "否")`
  - 账龄区间 (`S{i}`): `=IF(O{i}<=30, "1个月以内", IF(O{i}<=90, "1-3个月", IF(O{i}<=180, "3-6个月", IF(O{i}<=365, "6-12个月", "1年以上"))))`
  - 坏账计提比例 (`T{i}`): `=IF(O{i}<=30, 0.01, IF(O{i}<=90, 0.05, IF(O{i}<=180, 0.20, IF(O{i}<=365, 0.50, 1.00))))`
  - 坏账准备金额 (`U{i}`): `=ROUND(L{i}*T{i}, 2)`
  - 风险预警等级 (`V{i}`): `=IF(O{i}<=30, "无", IF(O{i}<=90, "蓝色", IF(O{i}<=180, "黄色", IF(O{i}<=365, "橙色", "红色"))))`
  - 建议措施 (`W{i}`): `=VLOOKUP(S{i}, '坏账准备与预警分析表'!$A$3:$J$7, 10, FALSE)`
- **Sheet 2 `坏账准备与预警分析表`**：
  - 单据笔数 (`D3:D7`): `=COUNTIF('应收账款明细(清洗后)'!$S:$S, A3)`
  - 未收余额合计 (`F3:F7`): `=SUMIF('应收账款明细(清洗后)'!$S:$S, A3, '应收账款明细(清洗后)'!$L:$L)`
  - 计提坏账准备 (`I3:I7`): `=ROUND(F3*H3, 2)`
  - 综合坏账计提率 (`H8`): `=I8/F8`
- **Sheet 3 `挂起异常清单` (13笔挂起明细)**
- **Sheet 4 `全部数据(含处置标记)` (120笔全量审计明细)**
- **Sheet 5 `客户标准信息表` (20家标准客户主数据档案)**

## 快速开始 (开发与构建)

> **前置环境**：Go 1.27+ 与 [Bun](https://bun.sh) 1.1+（注意：MyGo 工具链使用 `bun` 管理前端依赖与脚本）。

```bash
# 1. 安装前端依赖
bun install

# 2. 运行 Go 核心引擎与动态公式单元测试
go test -v ./internal/ar/...

# 3. 生成强类型 Go <-> TypeScript RPC 绑定
bun run generate

# 4. 启动桌面端热重载开发模式
bun run dev

# 5. 编译打包当前平台生产安装包 (输出至 build/ 目录)
bun run build
```
