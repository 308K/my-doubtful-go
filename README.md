3. **五步式智能数据治理流水线 (5-Step Pipeline)**
   - **Step 1 结构探测与清洗**：智能识别表头（第 4 行），自动剥离表头前冗余注释行（3 行）、过滤空白行（4 行：`[3, 21, 58, 102]`）、剔除小计/合计行（5 行：`[36, 68, 99, 131, 136]`）、哈希去重剔除重复单据（4 行：`[132, 133, 134, 135]`），从 136 行原始数据提纯出 **120 笔**有效业务记录。
   - **Step 2 主数据对齐与 8 类缺失值推导**：内置 20 家标准客户档案（`CUST001`~`CUST020`）别名反查；自动统计各客户历史有效账期众数并修补 8 类缺失值（账期 4、信用等级 2、已收金额 5、应收金额 6、未收余额 7、约定收款日 5、逾期天数 4、是否逾期 4，共 **37 处**缺失单元格）。
   - **Step 3 9 类财务异常审计与挂起分流**：
     - **6 类原地修复并入表**（应收金额为负 2、勾稽关系不平 3、账龄与开票日期矛盾 3、约定收款日与账期不符 3、逾期天数矛盾 3、逾期标识矛盾 2）；
     - **3 类实质性异常挂起隔离**（金额离群/低于 2 万元合理阈值 7 笔、已收大于应收溢缴超收 3 笔、未收余额为 0 仍挂账 3 笔，共 **13 笔**分流至《挂起异常清单》，确保 **107 笔**正常业务汇总基数真实准确）。
   - **Step 4 账龄测算与多维可视化看板**：支持动态调整报表基准日（默认 `2026-06-30`），实时联动账龄金字塔图、未收余额/坏账准备双环占比图、七大销售区域风险敞口雷达图，以及支持排序/多维筛选/单笔公式穿透复核的 TanStack 数据表格。
   - **Step 5 全量保留 Excel 原生动态公式导出**：生成包含 5 张工作表、**2,432 个原生 Excel 动态公式**的高保真财务工作簿。

## 全量动态公式架构 (`Excelize v2`)

导出的 Excel 工作簿绝不使用硬编码死数据，全部由 `'坏账准备与预警分析表'!$B$1`（`=DATE(2026,6,30)`）驱动级联重算：

- **Sheet 1 `应收账款明细(清洗后)` (107 笔正常明细)**：
  - 未收余额 (`L{i}`): `=J{i}-K{i}`
  - 约定收款日 (`N{i}`): `=G{i}+M{i}`
  - 账龄天数 (`O{i}`): `='坏账准备与预警分析表'!$B$1-G{i}`
  - 逾期天数 (`P{i}`): `=MAX(0, '坏账准备与预警分析表'!$B$1-N{i})`
  - 是否逾期 (`Q{i}`): `=IF(AND(P{i}>0, L{i}>0), "是", "否")`
  - 账龄区间 (`S{i}`): `=IFS(O{i}<=30, "1个月以内", O{i}<=90, "1-3个月", O{i}<=180, "3-6个月", O{i}<=365, "6-12个月", TRUE, "1年以上")`
  - 坏账计提比例 (`T{i}`): `=IFS(O{i}<=30, 0.01, O{i}<=90, 0.05, O{i}<=180, 0.20, O{i}<=365, 0.50, TRUE, 1.00)`
  - 坏账准备金额 (`U{i}`): `=ROUND(L{i}*T{i}, 2)`
  - 风险预警等级 (`V{i}`): `=IFS(O{i}<=30, "无", O{i}<=90, "蓝色", O{i}<=180, "黄色", O{i}<=365, "橙色", TRUE, "红色")`
  - 建议措施 (`W{i}`): `=VLOOKUP(S{i}, '坏账准备与预警分析表'!$A$3:$J$7, 10, FALSE)`
- **Sheet 2 `坏账准备与预警分析表`**：
  - 单据笔数 (`D3:D7`): `=COUNTIF('应收账款明细(清洗后)'!$S:$S, A3)`
  - 未收余额合计 (`F3:F7`): `=SUMIF('应收账款明细(清洗后)'!$S:$S, A3, '应收账款明细(清洗后)'!$L:$L)`
  - 计提坏账准备 (`I3:I7`): `=ROUND(F3*H3, 2)`
  - 综合坏账计提率 (`H8`): `=I8/F8`
- **Sheet 3 `挂起异常清单` (13 笔挂起明细)**
- **Sheet 4 `全部数据(含处置标记)` (120 笔全量审计明细)**
- **Sheet 5 `客户标准信息表` (20 家标准客户主数据档案)**

## 快速开始 (开发与构建)

> **前置环境**：Go 1.27+ 与 [Bun](https://bun.sh) 1.1+（注意：MyGo 工具链使用 `bun` 管理前端依赖与脚本）。

```bash
# 1. 安装前端依赖
bun install

# 2. 运行 Go 核心引擎与动态公式单元测试
go test -v ./internal/ar/...

# 3. 生成强类型 Go <-> TypeScript RPC 绑定
bun run generate

# 4. 启动桌面端热重载开发模式
bun run dev

# 5. 编译打包当前平台生产安装包 (输出至 build/ 目录)
bun run build
```
